Мотивация:

- Яндекс Метрика не видит API-заказы (B2B)
- Не знаем где теряются заказы
- Реактивное реагирование (узнаём о проблемах от клиентов)
- Нет данных для принятия решений об оптимизации

Выбор подхода к мониторингу:

| Компонент      | Подход                             |
| -------------- | ---------------------------------- |
| API сервисы    | RED                                |
| Инфраструктура | USE                                |
| RabbitMQ       | USE + специфичные метрики очередей |

Метрики:

| Метрика                          | Зачем                       |
| -------------------------------- | --------------------------- |
| Dead-letter-exchange in RabbitMQ | Потеря заказов              |
| Messages in flight in RabbitMQ   | Задержка обработки          |
| HTTP 500 для Shop/CRM/MES API    | Ошибки в системе            |
| Latency для Shop/CRM/MES API     | UX, SLA                     |
| RPS для Shop/CRM/MES API         | Нагрузка, capacity planning |
| CPU % для API                    | Насыщенность                |
| Memory для API                   | Насыщенность                |
| DB connections                   | Лимиты пула                 |
| DB size                          | Планирование                |
| S3 size                          | Costs, планирование         |

План действий:

1. Развернуть Prometheus + Grafana
2. Добавить экспортеры метрик:
   - Spring Boot Actuator + Micrometer (Shop API, CRM API)
   - prometheus-net (MES API на C#)
3. Настроить RabbitMQ Prometheus exporter
4. Настроить PostgreSQL exporter
5. Создать дашборды:
   - Overview (все сервисы)
   - Per-service (детали по каждому API)
   - Infrastructure (DB, RabbitMQ, S3)
6. Настроить Alertmanager + алерты

Пороговые значения и реакция:

| Метрика        | Порог       | Реакция                          |
| -------------- | ----------- | -------------------------------- |
| DLQ messages   | > 0         | Критический алерт → on-call      |
| HTTP 500 rate  | > 1%        | Алерт → Slack + тикет            |
| Latency p99    | > 2s        | Алерт → Slack                    |
| CPU            | > 80%       | Warning → планировать scaling    |
| Memory         | > 85%       | Warning → планировать scaling    |
| DB connections | > 80% пула  | Warning → проверить утечки       |
| DB size        | > 80% диска | Warning → планировать расширение |

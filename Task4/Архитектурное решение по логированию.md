КАКИЕ ЛОГИ СОБИРАТЬ:

Системы: Shop API, CRM API, MES API, RabbitMQ

INFO логи:
- Создание заказа
- Изменение статуса заказа
- Расчёт стоимости
- Отправка/получение RabbitMQ
- Загрузка 3D файла

Другие уровни:
| Уровень | Когда использовать                           |
|---------|----------------------------------------------|
| ERROR   | Исключения, failed operations                |
| WARN    | Таймауты, retry, degraded service            |
| DEBUG   | Детали для разработки (только dev/release)   |

ПРЕДЛАГАЕМОЕ РЕШЕНИЕ:

Технология: ELK Stack (Elasticsearch + Logstash + Kibana)

Политика безопасности:
- Не логировать PII (имена, email, телефоны клиентов)
- Маскировать чувствительные данные
- Доступ к Kibana:
  | Роль      | Права                |
  |-----------|----------------------|
  | Support   | Read-only            |
  | Developer | Read + search        |
  | Admin     | Full access          |
- Kibana за VPN или internal network

Политика хранения:
| Параметр      | Значение                              |
|---------------|---------------------------------------|
| Индексы       | shop-api-*, crm-api-*, mes-api-*      |
| Hot retention | 30 дней                               |
| Warm retention| 90 дней                               |
| Размер        | ~10GB/день (оценка)                   |

Алертинг и аномалии:
| Условие                         | Действие                    |
|---------------------------------|-----------------------------|
| ERROR rate > 1%                 | Алерт в Slack               |
| 0 логов > 5 мин                 | Критический алерт (сервис)  |
| Резкий рост запросов            | Алерт (возможно DDoS)       |
| Заказ без смены статуса > 1 час | Алерт (застрявший заказ)    |

См. диаграмму: c4-logging.drawio
